   → Read error messages on test.html

   → Re-run tests after fixing

================================================================================
⚠️ COMMON ISSUES & FIXES:
================================================================================

ISSUE: "Cannot write to data.json"
FIX: Set permissions to 666 (see step 4 above)

ISSUE: "API not found"
FIX: Make sure api.php is uploaded to correct folder

ISSUE: "Nothing saves"
FIX: 
  1. Run test.html to see exact error
  2. Check data.json permissions
  3. Check PHP version (needs 7.4+)

ISSUE: "Security warning about data.json"
FIX: Make sure .htaccess is uploaded (it protects data.json)

🎯 FILE PERMISSIONS GUIDE:
================================================================================

File              Permissions    Why?
---------------------------------------------------------
index.html        644 (default)  Public read, owner write
api.php           644 (default)  Public read, owner write
data.json         666 (MUST!)    Everyone read/write (PHP needs this)
.htaccess         644 (default)  Public read, owner write
test.html         644 (default)  Public read, owner write

Note: 666 for data.json is REQUIRED or saving won't work!

How to set 666:
- Method 1: Right-click → Permissions → Enter "666"
- Method 2: Right-click → Permissions → Check all Read + Write boxes
- Method 3: Use FTP client (FileZilla) → Right-click → Permissions → 666
