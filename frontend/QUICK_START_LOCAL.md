## 🛠️ OPTION B: Developer Setup

**If you want to modify code or build doesn't exist:**

### Windows Users:

```cmd
1️⃣ Install Node.js from https://nodejs.org/ (if not installed)

2️⃣ Open Command Prompt and navigate:
   cd C:\path\to\extracted\folder\frontend

3️⃣ Install dependencies:
   npm install
   (Wait 2-5 minutes)

4️⃣ Start the app:
   npm start

5️⃣ Browser opens automatically at http://localhost:3000
   🎉 DONE!
```

## ❓ FAQs

### Q: Do I need internet?
**A:** Only for initial setup (downloading Node.js, installing dependencies). Once running, it works offline.

### Q: Is it safe?
**A:** Yes! All PDF processing happens on your computer. No uploads, no cloud, no tracking.

### Q: Can I share this with friends?
**A:** Yes! Just zip the `frontend/build` folder and share. They double-click `index.html`.

### Q: What if I get errors?
**A:** Check the detailed guide: `LOCAL_SETUP_GUIDE.md`

## 🆘 Help! It's Not Working!

### Error: "node: command not found"
→ Install Node.js from https://nodejs.org/

### Error: Port 3000 in use
→ Close other apps or app will use port 3001 automatically

### Error: Blank page when opening index.html
→ Try using local server (see LOCAL_SETUP_GUIDE.md)

### Error: npm install fails
→ Delete `node_modules` folder and try again
