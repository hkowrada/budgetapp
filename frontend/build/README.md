# 🚀 PDF Manager Pro - Ready to Run!

## How to Run

### Windows:
Double-click **RUN_ME.bat**

### Mac/Linux:
Double-click **RUN_ME.sh**

## Features

- 🗜️ **3-Level Compression** (Lite/Medium/Heavy) - Up to 85% reduction!
- 🔗 **Merge PDFs** - Combine multiple files
- ✂️ **Delete Pages** - Remove unwanted pages  
- 🔄 **Delete + Merge** - Edit then merge
- 🔒 **100% Private** - All on your device

## Compression Levels

- **Lite**: ~20-30% smaller (Best quality)
- **Medium**: ~40-60% smaller (Balanced)
- **Heavy**: ~70-85% smaller (Maximum compression)

Keep the terminal open while using the app!
