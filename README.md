# 🌿 AGLOUD - India's First Rural Innovation Platform

A modern, responsive website showcasing AGLOUD's pioneering rural innovation ecosystem that integrates Agriculture, Aquaculture, BioTech, NanoTech, AI, Carbon tracking, and IoT.

## 🎯 Features

### Complete Sections
- **Hero Section**: Compelling introduction with clear call-to-action
- **About Section**: Vision, Mission, and Key Differentiators
- **Core Pillars**: 5 technology pillars with interactive cards
- **Ecosystem**: Stakeholder network displayed in a professional table
- **Technology Stack**: Overview of cutting-edge technologies
- **Flagship Programs**: 4 major initiatives
- **Team Section**: Leadership team with 6 members
- **Contact Section**: Working contact form with social links
- **Footer**: Inspirational message and copyright

### Technical Features
✅ **Fully Responsive**: Mobile, Tablet, Desktop, and TV-optimized
✅ **Performance Optimized**: Fast loading, minimal bundle size
✅ **Modern Design**: Following professional business network aesthetics
✅ **Smooth Animations**: Fade-in effects and hover interactions
✅ **Working Forms**: Contact form stores submissions in localStorage
✅ **Mobile Menu**: Hamburger navigation for mobile devices
✅ **Smooth Scrolling**: Seamless navigation between sections
✅ **Professional Icons**: Using Lucide React icon library
✅ **SEO Ready**: Semantic HTML structure

## 🚀 Quick Start for Hostinger Deployment

### Build Production Files
```bash
cd /app/frontend
yarn build
```

### Upload to Hostinger
Upload all contents from `/app/frontend/build/` folder to your Hostinger public_html directory.

**See [DEPLOYMENT_INSTRUCTIONS.md](./DEPLOYMENT_INSTRUCTIONS.md) for detailed guide.**

## 📝 Updating Content

All content is in `/app/frontend/src/data/mock.js`. After editing, rebuild and re-upload.
